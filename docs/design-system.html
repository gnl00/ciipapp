06

可访问性与验收

视觉与输入

  • 橙色主要动作的小字白色对比度至少 4.5:1；品牌标记与操作填色分开命名。
  • 保留 :focus-visible；鼠标操作不展示键盘环，键盘访问仍能识别位置。
  • 图标按钮必须有名称；百分比与工具提示不能被误选成文字。
  • 缩放、旋转与滚动保持原生输入反馈；窄窗口的工具溢出必须有可操作提示。

系统偏好

  • prefers-reduced-transparency 使用实色背景并关闭背景模糊。
  • prefers-reduced-motion 取消弹层移动与缩放；键盘开启、收起始终即时完成。
  • prefers-contrast:more 加强边线与辅助文字。
  • 在普通尺寸、最小窗口、复杂图片背景与弹出动画结束后检查材质。
