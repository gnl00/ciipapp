# 窗口与元素截图

窗口截图使用原生 AppKit 选择层。悬停高亮目标窗口，游标仅显示所属应用的真实图标，不显示相机、名称、窗口标题或信息卡片。元素截图使用十字游标，选区旁仅展示 `宽 × 高 px`。鼠标松开或按回车确认；Esc 或右键松开取消。选择层仅排除自身的遮罩窗口，贴图仍可作为截图目标。

元素截图入口位于编辑器截图菜单、应用截图菜单和菜单栏。悬停选择应用公开的辅助功能元素，↑ 选择外层、↓ 返回内层，单击或回车截取元素；按下后拖动超过 4 个逻辑点切换到区域框选，松开截取手动区域。框选可从没有 AX 元素的空白区域开始，支持反方向和跨显示器拖动，选区裁到桌面范围。拖动期间冻结自动命中并丢弃迟到的 AX 回包，尺寸与选框直接跟随指针；小幅手抖仍按元素单击处理。默认不分配全局快捷键，可在设置中绑定。未识别到有效元素时不能单击确认，可直接拖动框选；不会静默改为截取整个窗口。自绘画布、游戏或未提供辅助功能结构的应用可能只能识别容器，无法保证识别每个视觉元素。

## 权限与实现边界

所有截图仍需屏幕录制权限。仅元素截图额外调用 `AXIsProcessTrustedWithOptions`，首次使用由系统提示辅助功能授权；未授权时保留当前编辑器并给出设置路径。现有屏幕录制拖拽引导不申请辅助功能权限。

选择层通过 `CGWindowListCopyWindowInfo` 识别指针下最上层窗口，用 `NSRunningApplication` 读取应用图标，名称和元素描述仅用于辅助功能标签。元素识别向该应用的 AX 根对象发起命中测试，避免命中自身遮罩；鼠标跟踪事件立即采样，低频计时器补查遗漏的指针事件；后台单次查询合并为最新指针请求，复用当前应用的 AX 根对象。150ms 单次 IPC 超时与有界遍历防止目标应用拖住主线程。同一窗口内重新识别时保留最近有效的高亮，结果就绪后一次性替换，避免每次指针移动都先清空再恢复。仍命中同一最内层元素时保留用户选择的外层层级；切换窗口、窗口边界改变或确认无有效元素时清空旧选择。保留的画面不代表新指针位置已经确认：识别期间不能截图或切换层级，指针移出结果的最内层元素或目标窗口不匹配时，旧结果会被丢弃。

AX 命中可能只返回窗口或网页容器，不能直接把它当成最小元素。生产实现先在后台遍历包含指针的各个重叠分支，比较所有有效后代，避免只沿最小直接子节点下降而漏掉另一分支中的更小元素。等面积候选按几何位置稳定选择，同框父子优先更深元素，无边界的包装层继续下探；完整解析后再一次性发布从小到大的父级候选。未能解析到子元素的窗口/应用根节点不作为默认元素，避免先展示整个窗口再缩到小元素。父级边界达到窗口/屏幕裁切范围后停止，继续上行无法得到更大有效选区。子层查询受总时限、层数和每层候选数量约束，并检测循环，不会无限遍历整个页面。

部分 AX 提供者会短暂退回没有公开子节点的 Group。如果指针仍位于上次的最内层元素中，后台先重新读取该元素的实时边界并验证其父级链仍连接到此次命中的祖先，验证通过才保留小元素；移动、失效或不属于该祖先的旧元素不复用。慢回包到达时，若最新指针仍在结果的最内层元素内且窗口身份一致，可先更新选框，再查询最新精确位置；复查完成前仍禁止确认，避免连续微动令所有有效回包饥饿。

指针经过文字行或控件之间的空隙时，AX 也可能合法地命中整个页面容器。若新候选严格包含上一最内层元素、并会放大当前选框，自动放大先驻留 120ms，再重新查询当前指针位置确认；短暂穿过空隙不会立即把整个页面变亮再缩回。相同容器内微动不重新计时；命中下一元素、切换窗口或取消会丢弃候选。初次命中、兄弟元素切换和缩小仍即时更新。驻留期间保留的旧框不能用于截图，点击或回车须等待新选区确认并显示；当前精确位置已解析且没有查询在途时，↑ 可明确改选并显示该容器。驻留属于选择稳定性规则，减少动态效果不会关闭它。

`kAXErrorCannotComplete`、遍历超时和仅有窗口根节点的回包先视为临时未完成，保留上一有效画面并禁止确认，100ms 后在相同指针与窗口条件下重试，最多额外两次；不把短暂的 AX 预热误报为空区域，也不无限轮询不支持的界面。持续无法解析、明确不支持或确实不存在可选元素时才清空选区，取消与关闭后的重试和迟到回包都会被忽略。

高亮区域保留 1% 的非零绘制透明度作为鼠标命中面，避免完全透明的像素被 WindowServer 视为可穿透。选择层吞掉按下与拖动，在松开后才关闭并确认截图或取消；持键期间按 Esc 延迟到松开后取消，避免把剩余的松开事件留给下层应用。最终截图发生在选择层移除后，命中面不会写入图片。

每个显示器上的全屏选择窗口及其输入面、遮罩、边框和尺寸标签在整次选择期间保持常驻，不随指针移动重建。识别更新只改变目标矩形，显示通过 macOS 14+ 的 CADisplayLink 按帧指数跟随，旧系统使用动画计时器；新的目标从当前显示位置继续逼近，不重启固定起点动画。小于 0.75 个逻辑点的显示目标差异不触发重新追逐，语义边界与最终截图坐标仍使用精确数据。默认 120ms 的约 95% 收敛时间从共享 `--motion-capture-selection` 读取，接近目标 0.25 点时贴合停止。方向键、首次高亮、窗口选择、手动拖框和减少动态效果即时更新；结束、关闭与取消会停止时钟。

窗口与元素确认后优先通过进程内 ScreenCaptureKit 获取图片，直接返回 PNG 字节，不启动外部命令或写临时图片。macOS 14+ 的窗口截图使用窗口过滤器并去除阴影；元素/手动区域截图使用单显示器过滤、局部坐标与明确的输出像素尺寸，两种原生路径都显式排除鼠标光标。跨显示器区域保留原系统截图，以保持混合缩放和无光标语义。遮罩关闭后先刷新 AppKit/Core Animation 事务，再于下一主线程轮次请求新图像，不追加固定 180ms 睡眠。系统/API 不支持的情况显式回退到原 `screencapture` 路径，保留原先的合成等待；原生错误与取消不会被伪装成成功。最终 PNG 校验、自动复制剪贴板和文档语义不变。

快捷编辑在选择截图期间提前加载隐藏 WebView，页面等待真实图片交付后才建立文档。预加载窗口不接管编辑器命令、不显示；取消和失败会关闭它并释放等待，旧窗口的迟到回包不能进入新会话。确认后应用最终窗口边界再交付图片，画布经过绘制屏障后，按共享入场动效原位渐显；减少动态效果时立即显示。关闭按钮位于图片内侧右上角，短图自适应留白，极小图片保留外侧回退，避开缩放手柄。

AX 与 CG 坐标均为主显示器左上角起算的全局逻辑点，可为负数；AppKit 绘制使用左下角坐标，需要按主显示器高度转换。元素边界与窗口及当前显示器相交后向外取整，截取范围与快捷编辑定位使用同一个矩形，不把 Retina 图片像素当作屏幕点。元素截图为确认后屏幕上的内容，动态界面可能在识别和截图之间变化。

宽高读数按最终取整后的矩形乘以目标显示器缩放倍率计算，单位为图片像素。例如 Retina 显示器上的 `140 × 80` 屏幕点显示为 `280 × 160 px`。过渡时读数显示已识别目标的最终尺寸，不显示动画中途的虚拟尺寸。

原生遮罩使用 AppKit 系统颜色，窗口游标保留真实应用图标；元素的宽高使用等宽数字与系统实色背景，不展示应用信息。编辑器中的新增入口沿用现有菜单样式及共享 tokens。

## 验证

`testdata/capture-selection-drag.m` 覆盖单击与拖动阈值、正反方向、负坐标、桌面空白、迟到 AX 回包和完整取消事件序列，并可输出合成选框图。预加载状态测试覆盖图片等待、取消、迟回包隔离与命令归属；`testdata/native-capture.m` 在预先已授权的登录会话中仅捕获其自有合成窗口，检查尺寸、标题栏、阴影与遮罩移除。没有既有授权或 QA 窗口被遮挡时明确跳过实拍；光标正对照仅在指针位于 QA 内容中时执行。不申请权限或捕获用户内容。

`CGO_ENABLED=1 go test ./...` 包含 Go 坐标/参数测试和 `testdata/capture-selection.m` 原生夹具。夹具直接编译生产选择层，使用模拟的窗口和 AX 返回值检查窗口身份、元素边界、裁切、层级、无响应目标、取消与回调，并渲染真实 NSView。异步回归通过控制指针与 AX 响应时序，检查微小移动不清空高亮、外层选择保留、连续移动的请求合并、跨窗口过期结果丢弃、空结果清理和识别期间禁止确认。它不申请权限、不截取用户屏幕。

容器回归覆盖窗口根命中、重叠分支、兄弟顺序变化、同框父子、无边界包装层和 Group 粗回包：默认候选必须直接命中小控件，不能发布大容器中间态。异步回归验证同叶微动可先更新画面、跨叶和跨窗口旧结果被丢弃，以及旧元素移动后不被保留。临时失败回归检查旧框保留、不可确认，以及无须再次移动指针即可恢复。

空隙回归使用真实 picker 采样和生产图层，重放“小文字行 → 大容器 → 50ms 后下一行”，检查 33ms、83ms 的 presentation 选框和尺寸标签不扩成整页。它还检查稳定驻留后仍能选择容器、方向键主动放大、确认阻止旧框、离开后返回重新驻留、跨窗口和取消后的迟到计时器，以及减少动态效果下同样保留稳定性保护。

`testdata/capture-pointer-routing.m` 额外验证完整鼠标序列，并短暂显示本地 QA 窗口，用 `NSWindow.windowNumberAtPoint` 检查高亮中心的真实 WindowServer 命中结果。检查范围限定在一个忽略输入的 QA 栈标记之下，先确认遮罩区与底窗的排序已就绪，再检查高亮区域，避免系统屏蔽层或窗口尚未显示的时序造成误判。它不注入输入、不点击下层窗口，也不申请权限；必须在可访问 WindowServer 的 macOS 登录会话中执行。

`testdata/capture-selection-motion.m` 使用合成页面验证真实 presentation layer 的中间帧、动画中断接续、常驻遮罩、空结果、键盘即时响应、减少动态效果和窗口模式。Go 测试将从实际构建的 tokens 读取的收敛时长传给夹具；可额外输出起点、两个中间帧和终点 PNG，用于原生视觉检查。它不会截取用户桌面。

可另行输出仅含合成内容的原生渲染图：

```sh
mkdir -p build/capture-selection-qa
clang -fblocks internal/app/testdata/capture-selection.m \
  -framework Cocoa -framework ApplicationServices -framework QuartzCore \
  -o build/capture-selection-qa/regression
build/capture-selection-qa/regression build/capture-selection-qa
```

真实应用验收需另行覆盖：授权前后、鼠标首次点击与键盘取消、多个应用的控件层级、不支持 AX 的内容、窗口移动/关闭、Retina 与负坐标副屏、显示器变更、最终图片不包含遮罩，以及取消后原文档与窗口可见性的恢复。夹具不替代这些跨进程与系统权限验证。
